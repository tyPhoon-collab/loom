# Deploy Playground as a separate app

Loom will deploy Playground as a separate web app, linked from the documentation site and eventually hosted under a subdomain such as `playground.loom.dev`, while keeping its implementation in `apps/playground/`. We choose this boundary because Playground is a demo and onboarding surface, but its editor, wasm, audio, sharing, and future app-level dependencies should remain separate from the VitePress documentation build; the `apps/` directory also leaves room for future user-facing Loom apps beyond Playground without making those products part of the documentation source.
